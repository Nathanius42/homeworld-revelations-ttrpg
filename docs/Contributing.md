# Contributing

## Editing this wiki

The wiki is the `docs/` folder of this repository, published to Azure DevOps as a code wiki.

- Edit the Markdown files locally and commit and push them like any other change. You can also edit in the Azure DevOps web UI, which commits for you.
- Each `.md` file is a page. Each folder is a page group, and you can give a group an overview page by adding a `.md` file with the same name beside the folder.
- `.order` lists page names (without `.md`), one per line, to set the order they appear in.
- Page file names become page titles, so use readable names with hyphens for spaces, e.g. `Ship-Roster.md`.
- Spelling is Australian English throughout, except in code and direct quotations.

## Work tracking

Bugs and tasks are tracked in Azure Boards for this project. Mention a work item in a commit message as `#123` to link it.
